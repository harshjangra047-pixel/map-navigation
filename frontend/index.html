DSA Graph Inspector & Mathematical Breakdown

A* Evaluation Function

f(n) = g(n) + h(n)

g(n): Exact accumulated walking cost from starting node.

h(n): Euclidean straight-line distance to goal in 2D space: √((xdest-xn)² + (ydest-yn)²).

Admissibility: Because straight-line distance is the absolute shortest possible path between two points in metric space, h(n) ≤ h*(n), guaranteeing optimal paths.

Dijkstra Min-Heap Mechanism

std::priority_queue<pair<double, int>, ..., std::greater>

Relaxation: If dist[u] + weight(u, v) < dist[v], dist[v] is updated and v is inserted into the min-heap.

Time Complexity: O((V + E) log V).

Space Complexity: O(V) for predecessor and distance tables.

About SmartRoute CGC — Viva & Presentation Guide

1. Why Graph Theory for Campus Navigation?

Campus layouts are cyclic networks with intersections (vertices) and walkways (edges). Trees cannot represent alternate corridors or cycles. An Adjacency List is chosen because campus road graphs are sparse (average degree ~3.8 per landmark), using O(V + E) memory rather than O(V2) for an Adjacency Matrix.

2. Why Can BFS Not Replace Dijkstra on Campus Paths?

Standard BFS operates on unweighted graphs (counts hops). On campus, a path with 2 long walkways might take 10 minutes, whereas an alternative 3-segment walkway takes only 4 minutes. BFS minimizes edge hops, whereas Dijkstra minimizes total travel time.

3. How Does Simulated Traffic Affect Graph Edge Weights?

Each edge maintains a base walking time and congestion multiplier (LOW=1.0x, MED=1.5x, HIGH=2.5x). During Dijkstra/A* relaxation, the edge weight increases dynamically, shifting the optimal frontier around crowded student hubs.

4. How Are Road Closures Handled?

Setting edge.blocked = true causes the search algorithms to skip the edge in O(1) time without reallocating graph structures, demonstrating dynamic graph modification.
